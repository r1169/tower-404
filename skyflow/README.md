# Tower 404

Актуальные команды запуска, стек и описание трёх эпизодов находятся в [корневом README](../README.md).

Запуск из этой папки выполняется командой `py -m http.server 4174 --bind 127.0.0.1`. Адрес игры — http://127.0.0.1:4174/.

Выбор смены доступен через меню «Эпизоды» или голосом «эпизод один», «эпизод два», «эпизод три». Для запуска после вступления покажите ОК или скажите «начать смену». После победы команда «следующий эпизод» продолжает историю.

Эпизод 1 содержит 10 рейсов и обучение. Эпизод 2 содержит 14 рейсов, старые сводки и архивные аварийные вызовы. Эпизод 3 содержит 18 рейсов и восстановление связи, которое прерывается проверками Тимура. Прогресс ремонта и сюжетные сведения находятся под видом аэропорта.

После выдачи разрешений микрофону и камере голос задаёт распоряжение, жест ОК подтверждает его, палец вниз отменяет. Жест удерживается 0,5 секунды. Проверки по текстовым командам запускаются из корня репозитория командой `node scripts/test.cjs`. Реальные микрофон и камера требуют отдельной проверки на устройстве.
