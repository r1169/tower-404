Актуальное описание стека, команды, ограничений и плана находится в [корневом README](../README.md).

## Запуск только игры

Если терминал открыт внутри этой папки skyflow:

```powershell
py -m http.server 4174 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4174/ . Если сервер запущен из корня проекта Игра, адрес другой: http://127.0.0.1:4174/skyflow/ .

Нужны Chrome или Edge, интернет, микрофон и камера. До смены включите оборудование и выдайте разрешения. Для речи ключевое слово не требуется. Пример: «рейс двенадцать, посадка», затем жест ОК. Большой палец вниз отменяет. «Пауза», «продолжить», «журнал», «закрыть», «обучение» управляют экранами. Кнопки оставлены как резервный способ.

Распознавание речи использует сервис браузера; MediaPipe загружается из сети и обрабатывает кадры на устройстве. Состояние смены находится в памяти, рекорд и отметка обучения — в localStorage. Реальной оплаты пока нет.

## Проверки

Из корня проекта: `node scripts/test.cjs` или `npm test`. Тесты текстов и классов жестов не заменяют испытания настоящего микрофона и камеры.
