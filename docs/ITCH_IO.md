# Tower 404 — подготовка страницы itch.io

Версия архива: 0.16.0. Этот документ и сборка не означают, что игра уже опубликована.

## Сборка

Из корня репозитория:

```powershell
node scripts/test.cjs
py scripts/build_itch.py
```

На macOS/Linux замените `py` на `python3`. Дополнительные библиотеки не требуются.

Загрузочный файл: `output/itch/tower-404-0.16.0-html5.zip`. Рядом находится перечень файлов с контрольными суммами. `index.html` лежит в корне ZIP, пути относительные. Сборщик проверяет наличие и регистр имён ресурсов, ограничения размера и целостность архива. Включены только необходимые для запуска файлы; отчёты, тесты, локальные настройки и лабораторные материалы исключены.

Формат соответствует [официальной инструкции для HTML5-игр](https://itch.io/docs/creators/html5): ZIP с входным `index.html`, относительные пути, точный регистр имён и HTTPS для внешних ресурсов.

## Страница проекта

1. Войти в свой аккаунт itch.io и создать проект либо открыть существующую страницу Tower 404.
2. Название: **Tower 404**. Тип игры: **HTML** / запуск в браузере.
3. Загрузить ZIP и выбрать для него запуск в браузере. Оставить страницу черновиком до проверки предпросмотра.
4. Для широкого интерфейса выбрать **Click to launch in fullscreen**. Если используется встраивание в страницу, включить полноэкранную кнопку и прокрутку. Не отмечать Mobile Friendly до проверки на телефонах.
5. Заполнить описание, обложку и скриншоты. Публичность и модель оплаты выбрать отдельно с командой; текущая сборка открывает все три главы, реальной покупки нет.

## Короткое описание

Пиксельная сюжетная игра о ночной смене в диспетчерской. Резервный центр замолчал, самолёты продолжают прибывать, а некоторым сообщениям в эфире нельзя доверять. Управляйте рейсами вместе с Даной и Тимуром, сверяйте разрешения и удержите аэропорт до рассвета.

Три главы, голосовые команды и подтверждение жестами, ложные разрешения, аварийные ситуации и музыка, реагирующая на напряжение смены. Есть кнопки для резервного управления.

## Проверка перед публикацией

- Проверить загрузку меню, изображений, пролога, обучения и глав 2–3 именно в предпросмотре itch.io.
- Нажать в игре для запуска музыки; проверить настройки, паузу и возврат в меню.
- В Chrome/Edge включить голос и камеру, самостоятельно разрешить устройства. Проверить реальную фразу и жест ОК, затем выключить управление и убедиться, что устройства освобождены.
- Поддержка камеры и микрофона зависит от разрешений браузера и политики iframe на стороне платформы. Локальные тесты не доказывают работу внутри itch.io. Если платформа блокирует устройства, разобраться с ограничением до заявления о поддержке бесконтактной игры; полноэкранный режим сам по себе это разрешение не выдаёт.
- Для MediaPipe, шрифтов и браузерного распознавания речи нужен доступ к сети. Кадры камеры обрабатываются локально, распознавание речи может использовать сервис браузера. Игра не сохраняет записи устройств.
- Проверить посадку, вылет, подтверждение, отмену, результат и повтор смены. После этого открыть страницу для выбранной аудитории.

GitHub хранит исходники для команды; itch.io раздаёт собранную игру игрокам. Закрытый репозиторий GitHub не мешает отдельно загрузить браузерный ZIP на itch.io.
