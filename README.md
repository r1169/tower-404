# Tower 404

Репозиторий проекта: https://github.com/r1169/tower-404

Сюжетная пиксельная игра управления ночным аэропортом. Игрок выбирает рейсы голосом, подтверждает приказы жестами и распределяет ограниченные ресурсы. Дана ведёт движение, Тимур проверяет подозрительные борта.

Актуальная версия: **0.16.0** — переработанные главы 2–3, подтверждённые ранние заходы, плотный поток, сюжетные разговоры с портретами на паузе и адаптивная музыка.

## Запуск

Нужны Python 3 для локального сервера, Chrome или Edge, камера, микрофон и интернет. Из корня проекта:

```powershell
py -m http.server 4174 --bind 127.0.0.1
```

Открыть **http://127.0.0.1:4174/skyflow/**. Адрес без `/skyflow/` показывает каталог проекта. Оставить терминал открытым; Ctrl+C останавливает сервер. Если `py` отсутствует, установить Python 3 или указать путь к доступному интерпретатору. Запуск из VS Code и PyCharm одинаковый: открыть папку и встроенный терминал.

До смены включить голос и камеру и самостоятельно выдать браузерные разрешения. При обновлении файлов использовать Ctrl+F5. Открытие HTML двойным щелчком не является проверенным способом работы распознавания.

## Управление

- «Начать смену», «обучение», «дальше», «пропустить обучение».
- «Рейс двенадцать, посадка», «рейс двадцать три, проверка», «взлёт», «изолированная стоянка», «ожидание».
- ОК — кольцо большим и указательным пальцем — подтвердить приказ; большой палец вниз — отменить. Между подтверждениями убрать жест.
- «Пауза», «продолжить», «журнал», «закрыть», «главное меню».
- «Вызвать аварийные службы», «тише», «громче», «выключить звук».
- «Музыка тише», «музыка громче», «включить музыку», «выключить музыку». Отдельная громкость также доступна в «Настройки → Звук и музыка»; она сохраняется в браузере.

Ключевое слово «башня» не требуется. Говорить по одной короткой команде. Кнопки служат резервным способом управления и демонстрации UI.

Музыкальная тема «Пульс башни» меняет темп и плотность ритма по реальной нагрузке, запасу топлива и объявленным опасным ситуациям. Во вступлениях звучит отдельная активная мелодия. На паузе и при репликах музыка тише. Композиция создаётся через Web Audio API без скачивания аудиозаписей.

## Что реализовано

Три сюжетные главы: меню «Эпизоды» или голосом «глава два», «глава три». Основа актуальной версии импортирована из обновлённой игры на рабочем столе 13.11.2026; затем доработана вторая глава (15.11.2026): три волны, разговоры на паузе, посадка 404 только в финале.

| Глава | Объём | Особенности |
|---|---:|---|
| Последние в башне | 10 рейсов | Пролог, обучение, прибытия волнами, временные закрытия полос |
| Не отвечайте на вызов | 13 самолётов + 1 фантом | Три волны подмен, ложная срочность и требование изоляции, старое разрешение, чужой заход, посадка 404 в финале, разговоры на паузе |
| Последняя запись | 16 самолётов, включая 3 вылета | Три этапа, архив на паузе, отказ шасси и подготовка полосы, помехи связи, общий канал для самолёта и записи, три исхода доказательств |

Во второй главе голосом доступны «рейс 42 камера», «рейс 42 снять отметку», «рейс 35 отказать в приоритете», «рейс 56 сверить журнал», «рейс 56 отменить разрешение», «рейс 95 второй круг». Распоряжение подтверждается ОК; палец вниз отменяет подготовку. Второй круг длится 22 секунды и расходует около 7% топлива. Самолёт возвращается в ожидание и требует нового разрешения. Подтверждённый ранний заход можно принять командой «рейс 57 принять заход»; ненужный второй круг снимает 4 репутации. Опасный заход нужно отменить: его игнорирование заканчивается столкновением с техникой и поражением. У ложных сигналов и необоснованной изоляции есть последствия для ресурсов и репутации. Во время сюжетных разговоров смена остановлена: «дальше» или ОК листает реплики, палец вниз возвращает к предыдущей. Подробности и голосовые примеры — в `skyflow/README.md`.

В третьей главе: «рейс 56 подготовить полосу», «первая полоса» и посадка 56; «освободить канал», «рейс 91 резервная частота» и затем посадка. Архив и самолёт конкурируют за резервный канал. Важные разговоры идут на паузе, сюжетные решения требуют отдельного подтверждения.

После победы — «следующая глава»; ОК на результате второй главы также открывает третью. «Повторить главу» перезапускает текущую. Во второй и третьей главах коллеги разговаривают в передышках; после происшествий шутки отключаются. Сюжетные окна компактные, с портретом и именем говорящего, архивный голос явно помечен. Все главы доступны для тестирования; рекорды хранятся локально. Есть полосы и стоянки, топливо, проверки, аварии, расчистка, журнал, пауза и звук.

## Стек

HTML, CSS, JavaScript, Canvas 2D, Web Speech API, MediaPipe GestureRecognizer, Web Audio API, localStorage. Python раздаёт статические файлы, не исполняет игровую логику. Node.js используется для тестов, сборщик и npm-зависимости для самой игры не нужны.

Кадры камеры обрабатываются на устройстве; модель и библиотека MediaPipe загружаются из сети. Браузерное распознавание речи может отправлять аудио сервису браузера и зависеть от интернета. Игра не сохраняет записи камеры и микрофона. Качество распознавания на реальных устройствах проверяется отдельно от текстовых тестов. Прогноз нагрузки пока алгоритмический, обученной модели прогноза нет.

## Проверки

Установить Node.js. Из корня:

```powershell
npm test
```

Либо без npm: `node scripts/test.cjs`. Проверяются симуляция, последствия, речь как текст, фильтр жестов, обучение, диалоги, анимация, восстановление полос и проходимость. Проверки не заменяют испытания настоящего микрофона и камеры.

## Архив для itch.io

После `node scripts/test.cjs` выполните `py scripts/build_itch.py` (на macOS/Linux — `python3 scripts/build_itch.py`). Готовый архив находится в `output/itch/tower-404-0.16.0-html5.zip`. В его корне лежит `index.html`; внутрь включаются только игровые скрипты, стили и используемые изображения. Проверки, отчёты, учебные материалы и Git не включаются.

Сборка не публикует игру. Настройка страницы и проверка камеры/голоса во встроенном окне описаны в [инструкции itch.io](docs/ITCH_IO.md).

## Коммерциализация и ограничения

План: бесплатный эпизод 1 и разовый доступ к эпизодам 2 и 3. Цена 1500 ₸ является гипотезой. Эпизоды 2–3 реализованы и доступны для тестирования. Реальные платежи, сервер лицензий и аккаунты остаются будущей работой в архитектуре и WBS. localStorage хранит игровой прогресс.

До коммерческого выпуска необходимо проверить права и лицензии используемых материалов, моделей, библиотек и шрифтов. Публичная лицензия на весь проект пока не выбрана. Игра является учебной и не предназначена для реального управления воздушным движением.
