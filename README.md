# Tower 404

Репозиторий проекта: https://github.com/r1169/tower-404

Сюжетная пиксельная игра управления ночным аэропортом. Игрок выбирает рейсы голосом, подтверждает приказы жестами и распределяет ограниченные ресурсы. Дана ведёт движение, Тимур проверяет подозрительные борта.

## Запуск

Нужны Python 3 для локального сервера, Chrome или Edge, камера, микрофон и интернет. Из корня проекта:

```powershell
py -m http.server 4174 --bind 127.0.0.1
```

Открыть **http://127.0.0.1:4174/skyflow/**. Адрес без `/skyflow/` показывает каталог проекта. Оставить терминал открытым; Ctrl+C останавливает сервер. Если `py` отсутствует, установить Python 3 или указать путь к доступному интерпретатору. Запуск из VS Code и PyCharm одинаковый: открыть папку и встроенный терминал.

До смены включить голос и камеру и самостоятельно выдать браузерные разрешения. При обновлении файлов использовать Ctrl+F5. Открытие HTML двойным щелчком не является проверенным способом работы распознавания.

## Управление

- «Начать смену», «обучение», «дальше», «пропустить обучение».
- «Рейс двенадцать, посадка», «рейс двадцать три, проверка», «взлёт», «изолированная стоянка», «ожидание».
- ОК — кольцо большим и указательным пальцем — подтвердить приказ; большой палец вниз — отменить. Между подтверждениями убрать жест.
- «Пауза», «продолжить», «журнал», «закрыть», «главное меню».
- «Вызвать аварийные службы», «тише», «громче», «выключить звук».

Ключевое слово «башня» не требуется. Говорить по одной короткой команде. Кнопки служат резервным способом управления и демонстрации UI.

## Что реализовано

Одна смена на 10 рейсов с тремя ступенями нагрузки; полосы и стоянки, топливо, подозрения и проверки, ложные сигналы, срочные прибытия, аварии и расчистка. Есть вступление и учебные шаги, ситуативные реплики, журнал, победа, поражение, повтор, звук и локальный рекорд.

## Стек

HTML, CSS, JavaScript, Canvas 2D, Web Speech API, MediaPipe GestureRecognizer, Web Audio API, localStorage. Python раздаёт статические файлы, не исполняет игровую логику. Node.js используется для тестов, сборщик и npm-зависимости для самой игры не нужны.

Кадры камеры обрабатываются на устройстве; модель и библиотека MediaPipe загружаются из сети. Браузерное распознавание речи может отправлять аудио сервису браузера и зависеть от интернета. Игра не сохраняет записи камеры и микрофона. Качество распознавания на реальных устройствах проверяется отдельно от текстовых тестов. Прогноз нагрузки пока алгоритмический, обученной модели прогноза нет.

## Проверки

Установить Node.js. Из корня:

```powershell
npm test
```

Либо без npm: `node scripts/test.cjs`. Проверяются симуляция, последствия, речь как текст, фильтр жестов, обучение, диалоги, анимация, восстановление полос и проходимость. Проверки не заменяют испытания настоящего микрофона и камеры.

## Коммерциализация и ограничения

План: бесплатный эпизод 1 и разовый доступ к эпизодам 2 и 3. Цена 1500 ₸ является гипотезой. Реальных платежей, сервера лицензий, аккаунтов и отдельных готовых эпизодов 2–3 пока нет. Они включены в архитектуру и WBS как будущая работа; localStorage не доказывает оплату.

До коммерческого выпуска необходимо проверить права и лицензии используемых материалов, моделей, библиотек и шрифтов. Публичная лицензия на весь проект пока не выбрана. Игра является учебной и не предназначена для реального управления воздушным движением.
